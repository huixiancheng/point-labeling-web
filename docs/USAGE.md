# 使用说明 / User guide

这份文档面向拿到 Windows 包后直接使用标注工具的人。源码构建和测试见 [`DEVELOPMENT.md`](DEVELOPMENT.md)。

## 1. 启动

解压后不要改变 `app`、`clips`、`logs` 的相对位置：

```text
PointLabelingWebOpen-Windows-<date>/
├─ PointLabelerLauncher.exe
├─ app/
├─ clips/
├─ logs/
└─ update/
```

把公开数据放进 `clips`，日常使用推荐双击 `PointLabelerLauncher.exe`，选择“开启标注”。默认地址是：

```text
http://localhost:8090/
```

启动器提供“开启标注、结束标注、更新、退出程序”四个核心操作；标题栏“最小化”和“隐藏到托盘”是独立的窗口管理功能。开启标注会在后台运行服务并自动打开浏览器，不会留下需要一直挂着的 PowerShell 窗口。结束服务时选择“结束标注”。发布包只保留 EXE 入口，避免脚本入口造成重复服务。

启动器中的“退出程序”会关闭启动器窗口并结束当前发布包的标注服务；如果希望先看到明确的停止状态，可以先选择“结束标注”。

标题栏“最小化”和启动器内的“隐藏到托盘”是两个独立功能：前者保留任务栏恢复入口，后者隐藏任务栏窗口但保持服务运行，只通过托盘恢复。托盘图标支持单击恢复，右键可以显示、开启、结束或退出程序。关闭窗口或从托盘退出时，会先提醒网页可能存在未保存标签，请先确认页面显示“0 个待保存”。

端口和性能模式直接在启动器中设置。

可选性能模式：

| 模式 | 默认窗口 | 适合场景 |
| --- | ---: | --- |
| `auto` | 自动选择 | 普通使用；由浏览器 GPU 信息决定。 |
| `high` | 200 帧 | 独立显卡或高性能机器。 |
| `low` | 1 帧 | Intel 集显、内存/显存紧张或需要降低交互延迟。 |

模式只改变浏览器加载和显示窗口，不修改原始点云，也不丢弃服务端读取的完整点。

启动器中的“更新”要求把新版本的 `app` 解压到 `update\app`；如果启动器本身也更新，同时放入 `update\PointLabelerLauncher.exe`。更新完成后会保留 `clips` 和 `logs`，并在需要时自动替换启动器。

发布包默认从 `clips` 递归扫描数据。需要调试包外数据时，请使用开发环境中的前台服务命令，不要在发布包中另行启动第二个服务。

## 2. 数据放置

服务会递归扫描数据根目录，自动识别 `velodyne` 帧目录。推荐结构：

```text
clips/
└─ semantic_kitti/
   └─ sequences/
      └─ 00/
         ├─ velodyne/000000.bin
         ├─ velodyne/000001.bin
         ├─ labels/000000.label
         ├─ poses.txt
         └─ calib.txt
```

可以放多个 Clip 或多个序列；页面顶部的 Clip 下拉框会列出扫描结果。只有一个 Clip 时会自动打开。文件名按数字帧号配对，例如 `000123.bin` 对应 `000123.label`。

支持的输入边界和 KITTI Object 的注意事项见 [`OPEN_FORMATS.md`](OPEN_FORMATS.md)。

## 3. 标注页面

### 语言和显示

顶部“语言”下拉框切换 `中文` / `English`。选择保存在当前浏览器的本地设置，下次打开继续使用。语言切换只改变界面文字和标签名称，不改变数据文件。

顶部还可以调整：

- 性能模式：自动、高性能、集显/低性能。
- 背景与标注颜色：深色背景或浅色背景。
- 界面缩放：75%–120%，适合小分辨率显示器。
- 播放速度和默认播放器。

### 工具

- 视角：旋转、平移和缩放点云。
- 画刷：在固定 3D 世界尺度内标注点，半径当前为 1–100，默认 8。
- 多边形、矩形、套索：按屏幕范围选择点。
- 折线：在点云上点击路径端点；画刷半径控制 XY 范围，折线高度过滤控制相对折线高度的范围。默认高度过滤值 15 对应约 ±15 cm（数据坐标单位为米时）。
- 工作区：点击左侧工具栏按钮，在鸟瞰视图中定义 XY 工作区，限制显示和操作范围；不绑定键盘快捷键，避免与飞行视角的 `W` 移动键冲突。
- 地面过滤：显示全部点、隐藏地面或仅显示地面。

画刷和折线的半径不是随相机缩放变化的屏幕像素值，而是固定的世界尺度；这样调整视角后标注宽度不会跟着屏幕比例改变。

### 标注范围和状态

“当前窗口”会把操作应用到当前已加载窗口的帧；“仅当前帧”只作用于当前帧。高性能和低性能模式会自动选择默认范围，也可以在页面中手动改。

时间线颜色表示工作状态：

- 未修改：本次会话还没有修改。
- 已保存修改：已经写回标签文件。
- 待保存：内存中有修改，尚未写回。
- 已加载窗口：当前浏览器已载入的帧范围。

## 4. 保存和导出

- `Ctrl+S`：保存全部待保存帧。
- “保存当前帧”：只保存当前帧。
- “导出当前帧标签”：下载标准 SemanticKITTI/KITTI `.label`。
- “导出 Clip 标签”：下载包含 Clip 元数据、帧标签和修改记录的 `.plwlabels`。

保存采用原子写入并按帧处理；未修改点的原始 `uint32` 标签会保留。关闭页面或切换 Clip 前，如果存在待保存修改，页面会先询问保存、放弃或取消。

## 5. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `N` | 视角工具 |
| `1`–`5` | 画刷、多边形、矩形、套索、折线 |
| `V` | 循环视角 |
| `B` | 鸟瞰；再次按回到上一次自动透视视角，不会进入飞行视角 |
| `F` / `G` | 飞行视角开关 |
| `Enter` / 右键 | 应用当前工具预览 |
| `Delete` | 删除最后一个多边形/折线/工作区顶点 |
| `Ctrl+S` | 保存全部 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Alt+0`–`Alt+9` | 选择对应标签类别（类别存在时） |

## 6. 故障排查

### 网页打不开

1. 确认使用的是启动器中填写并显示的端口。
2. 检查 `logs/server.log`。
3. 如果端口冲突，换用 `-Port 18090` 等空闲端口。
4. 确认 `app\point_labeler_server.exe`、`app\assets`、`app\web` 都存在。

### 找不到 Clip

- 确认数据放在发布包的 `clips` 下；开发前台服务则确认 `DataRoot` 指向数据目录。
- 确认目录中存在 `velodyne` 和连续编号的 `.bin`。
- 首次打开时等待 Clip 扫描完成；多 Clip 时在顶部选择。
- 不能把只有 KITTI `label_2/*.txt` 的框标注目录当作逐点 `.label` 使用。

### 启动进程立即退出

发布包启动失败时先查看 `logs/server.log`。需要前台查看详细错误时，请先按 [`DEVELOPMENT.md`](DEVELOPMENT.md) 完成后端构建，再直接运行服务：

```powershell
.\server\build_open\Release\point_labeler_server.exe `
  --root "D:\datasets\SemanticKITTI" `
  --assets .\server\assets `
  --web-root .\frontend\dist `
  --log .\logs\server-foreground.log `
  --host 127.0.0.1 `
  --port 18090
```

重点查看 Qt DLL、`assets/web` 路径、端口占用和日志路径。前台运行时窗口保持打开是预期行为；发布包日常使用 `PointLabelerLauncher.exe`。

### 集显卡顿

将性能模式设为“集显/低性能”，把帧显示设为“仅当前帧”，把标注范围设为“仅当前帧”，并适当缩小点大小。完整点仍由服务端按帧读取，不会因为显示优化而改变标签文件。

## 7. 本地服务边界

默认服务绑定 `127.0.0.1`，只允许本机浏览器访问，不会自动把数据开放到局域网。若要让其他机器访问，需要明确修改监听地址并自行配置防火墙；这不属于默认发布包行为。
